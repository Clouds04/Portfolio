Ce que je sais faire

🖥 Administration Windows Server Active Directory (AD DS), DNS, DHCP, GPO, WSUS, gestion des utilisateurs et groupes, déploiement de rôles et fonctionnalités.
🐧 Administration Linux Installation et configuration Debian/Ubuntu, gestion des services (systemd), durcissement SSH, Fail2ban, UFW, serveur Apache/Nginx.
📡 Configuration réseau Adressage IPv4/IPv6, subnetting, configuration CLI Cisco (VLAN, STP, routage inter-VLAN, spanning-tree), protocoles OSPF, RIP (notions).
🔒 Sécurité périmétrique Firewall pfSense (règles, NAT, VLAN), VPN OpenVPN site-à-site, certificats SSL/TLS, ACL Cisco, analyse de trafic Wireshark.
☁️ Virtualisation VMware ESXi/vCenter (création VM, snapshots, templates), Hyper-V, Docker (conteneurs, images, docker-compose), Proxmox.
📊 Supervision & support Zabbix (hôtes, triggers, alertes), GLPI + Fusion Inventory (inventaire auto, tickets), SNMP, gestion de parc ITSM.
